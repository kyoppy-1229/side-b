更新: 2026-10-29 / ソースと新規記事画像10枚をローカルに追加。GitHubへのpush・Pages公開は未実施。

## 今回実装したこと

- 既存34サイトに2016〜2025年の一般記事を追加。既存217ページから813ページへ増加。閉鎖済みサイトや更新終了サイトは、最終更新日以後の記事を作らない。
- 端末の読み方、ログの文字列検索、記録比較、過去記事の日付の見方など、物語の核心に触れない6本の解説記事を別々のサイトに掲載。
- 第8章以降で開ける `https://grad2015.school.local/terminal` を追加。復刻版・体験版の序盤に黒幕情報が漏れないよう、物語ステータスで閲覧制限。
- 卒業した10人のうち主人公を除く9人に聞き込み。保存資料から8人のアリバイを照合すると最後の1人に収束。
- 校内PCの読み取り専用コマンドシミュレーター。`HELP` / `DIR` / `TYPE` / `FINDSTR` / `FC` / `TIMELINE` / `CLS` に対応。入力はJavaScriptで固定データを検索するだけであり、OSのシェルや外部ネットワークには一切接続しない。
- 聞き込み、資料閲覧、アリバイ除外を個別に保存。ゲーム本編・体験版・デバッグのストレージスコープを継承。
- `docs/asset-prompts-final-mystery.md` に人物・校舎・物証・年別記事の画像生成指示を収録。
- 2016〜2025年に対応するオリジナルWeb記事画像10枚を生成してWebPに変換（合計約1.8MB）。関連する年次記事と4本の解説記事の画像参照を更新。

## ローカルで確認する

1. `npm ci`
2. `npm run dev`
3. ブラウザで `#/debug` を開く。
4. デバッグメニューの「ページ直接オープン」から「最終章：聞き込み＋校内PC（試作）」をクリック。
5. 9人に二段階で質問。校内PCで `DIR` → `TYPE` で資料を確認し、8人のアリバイを除外。`ACCESS.LOG`、`SESSION.LOG`、`BACKUP.LOG` を読んだ上で「最後の一人を特定する」。
